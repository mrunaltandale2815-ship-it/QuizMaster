Quiz Master is a web-based quiz application built using HTML, CSS, and JavaScript. Users can choose different categories, answer multiple-choice questions, and view their scores.

Features :-
Multiple quiz categories
2-minute countdown timer
Automatic score calculation
Result and answer review
LocalStorage for saving quiz data
Technologies

HTML5 • CSS3 • JavaScript • LocalStorage

Purpose :-
This project was created to practice JavaScript, DOM manipulation, events, timers, and LocalStorage while building an interactive quiz application.
